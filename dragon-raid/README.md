# 屠龙战纪（dragon-raid）

抖音直播弹幕互动游戏，魔幻屠龙题材。**观众自己当英雄，主播不用操作。**

观众发弹幕选职业加入，头像变成一个英雄，在画面下方三条航道里自动战斗；上方是一章一条的巨龙（还有深渊魔王）。观众用弹幕躲技能、放大招、给自己那条航道的**屠龙巨弩**上弦、投票选**神殿祝福**，用礼物锻造神器、召唤帮手。

和《星舰弹幕战》用的是同一套已经验证过的骨架（主播挂机、熙梦接入、章节闯关、6部位×6品质装备、锻造保底、英灵附体代打、后援、存档），但玩法上有这些**新东西**：

| 新玩法 | 说明 |
|---|---|
| 屠龙巨弩 | 三条航道底部各一台。站在这条道上的观众发「装填」一起上弦，满了射出屠龙鱼叉：重创巨龙并攒破甲；没有BOSS时鱼叉贯穿整条航道，沿途魔物一击必杀。站哪条道不再只是为了躲技能 |
| 巨龙升空 / 击落 | 赤焰龙王、冥骨巫龙、冰霜巨龙半血后会定期飞上天10秒：普通攻击只剩1/4伤害，还往下砸「天火」。只有巨弩鱼叉能把它射下来——射中直接摔倒在地 |
| 破甲倒地 | 巨弩、骑士盾击、旋风斩、点赞英勇一击都攒破甲，满了巨龙轰然倒地8秒：所有蓄力中的技能被打断、附属物停火、**受到伤害×2**。每倒一次下次需要的破甲多25% |
| 神殿祝福 | 每章第1关开打时弹出3个祝福，观众发 **A / B / C** 投票15秒，**本章送过礼的人一票顶5票**，得票最多的整章生效（烈焰附魔、圣光庇护、贪婪之心……） |
| 四象阵 | 一条航道里同时有法师、骑士、牧师、游侠（活着的，含NPC和佣兵），脚下亮起法阵，这条道攻击+15%、受伤-10%。鼓励观众互相喊人转职、换道 |
| 屠龙勇者 | 每打死一条章节巨龙，贡献第一的人戴上屠龙王冠（名字上方、战力榜、开局页都显示），直到下一条龙被屠；存档记每个人的屠龙次数 |

## 主播怎么用

1. 先打开熙梦并连接直播间（默认端口 8765，和凌霄守山、星舰弹幕战一样）。
2. 用 Chrome 或 Edge 打开部署好的 **https://** 网址。浏览器问「访问本地网络 / 本机应用」时点 **允许**。
3. 页面会自动连熙梦。按 **F2**（或点右侧中间的 ⚙）打开设置面板，可以看连接状态、改端口和参数。
4. 游戏窗口单独放一个窗口，在直播伴侣 / OBS 里用 **窗口捕获**，不要最小化。直播前把设置面板收起。
5. 建议在 Chrome「设置 → 性能」里把游戏网址加入「始终让这些网站保持活动状态」。
6. 同一时间只能开一个游戏页面；再开第二个会提示关闭，避免同一份礼物结算两次。

设置面板里改完自动保存、马上生效。**默认：背景音乐开（程序合成的史诗魔幻配乐，战斗中加战鼓和铜管）、音效开、语音播报关、补位NPC 4个**；浏览器要求先在页面上点一下鼠标才会出声。

没连熙梦时，设置面板里有测试按钮：加入20个测试观众（四职业轮流）、按名字发各种礼物、测试装填、测试投票、测试举盾、测试点赞（测试观众不写入存档）。连上熙梦后测试按钮自动禁用。

## 观众玩法

| 弹幕 | 效果 |
|---|---|
| 法师 / 骑士 / 牧师 / 游侠 | 转职加入（也认「输出」「坦克」「奶」「弓箭手」等），存档记住；发「加入」自动补缺的职业 |
| 左 / 中 / 右（或 1 / 2 / 3） | 换航道：躲危险区、去别的巨弩、凑四象阵 |
| 装填 | 给自己所在航道的巨弩上弦（也认「上弦」「巨弩」），每人每1.5秒算一次 |
| A / B / C | 神殿祝福投票（也认「选A」「祝福B」） |
| 大招 | 放大招（冷却45秒；快好时发会排队，好了自动补放） |
| 举盾 | 「灭世龙息」锁定时全员发，每次削弱1.5%，最多60% |
| 我的 / 装备 | 弹出自己的属性卡 / 6件装备详情 |
| 签到 | 每天领一次每日战利品 |
| 点赞 | 聚集士气（满500全队伤害+10% 15秒）；每10个赞给巨弩装填1次 |

## 四大职业

小技能每10秒自动放；大招要观众发「大招」（英灵附体的自动放）。

| 职业 | 血量 / 攻击 | 小技能 | 大招 |
|---|---|---|---|
| 法师 | 100 / 10 | 火球术：8枚追踪火球 | 烈焰洪流：自动瞄准的火焰射线2.5秒 |
| 骑士 | 260 / 5，减伤35% | 盾击：扇形冲击波，震退魔物、打散火球、嘲讽，打到巨龙攒破甲 | 旋风斩：无敌4秒冲进怪堆旋风斩（打巨龙也攒破甲） |
| 游侠 | 150 / 6，减伤15% | 灵鹰：放4只灵鹰追着怪打 | 鹰群风暴：10只守护灵鹰在英雄区巡逻拦截火球 |
| 牧师 | 90 / 4，减伤10% | 治疗术：给血量最低的3人回血（没人掉血改加护盾） | 圣光普照：复活阵亡队友，5秒持续群体回血 |

骑士站最前排，法师居中，游侠和牧师在后排；骑士普攻是冲上去近战砍，附近没怪时冲到巨龙身下砍要害。

| 爱你哟（52）· 战鼓 | 全队攻击+30% 60秒；**万箭齐发**5秒/个（每箭=送礼人攻击×2）；自己掉落保底传说装 |
| 墨镜（99）· 狮鹫骑士 | 自己普攻+30%、狮鹫骑士护驾5分钟（跨关保留）；自己掉落保底史诗装 |

| 跑车（1200）· 宝箱怪 | 宝箱怪出没（当前BOSS血量40%），打死后全员开箱；打过它的人拿10倍BOSS经验；送礼人保底1件至尊红装 |
| 任意礼物 | **英灵附体**：每1抖币12秒，自动躲危险区、自动放大招、**每3秒自动装填巨弩**；**每1抖币直接给自己航道的巨弩装填1次**；本章祝福投票一票顶5票 |

先按礼物名认，认不出按单价；设置面板里可以追加「礼物名=效果」。开战前送的礼物记下来开战后生效。

## 关卡与BOSS

**每章5关**：1–3关魔物（雏龙、爆裂蝠、龙人术士）约21–30秒后**龙人督军**现身，打死过关；第4关是下一章巨龙的精英形态（半血）；第5关屠龙。每关限时2分钟。全军覆没或超时退回上一章第1关。

| 章 | BOSS | 招式 | 附属物（可打掉，40秒重生） |
|---|---|---|---|
| 1、5、9… | 赤焰龙王 | 龙炎弹幕；龙爪撕裂（单路）、烈焰吐息（两路）、狂暴后**灭世龙息**（两路110%，可「举盾」）；**会升空** | 4个龙焰图腾：扇形/螺旋火球 |
| 2、6… | 冥骨巫龙 | 追踪鬼火；瘟疫毒池（持续5秒每秒14%）；狂暴后「亡者大军」；**会升空**；这一章的小怪是骷髅兵 | 2个墓碑：不停爬出骷髅兵 |
| 3、7… | 冰霜巨龙 | 冰锥雨；寒冰射线（先预警再旋转扫过）；冰刺左→中→右依次爆发；**会升空** | 3个冰晶：三连冰矢 |
| 4、8… | 深渊魔王 | 魔焰弹幕；魔眼凝视（锁定贡献最高的人那条道）；狂暴后深渊漩涡把英雄往中间吸 | 4个魔眼：扇形/螺旋弹幕 |

难度按章涨：首领血量第1章2.2万，1–5章每章×1.5，6–10章×1.8，11章起每章翻倍。

## 装备与成长

和星舰弹幕战同一套经济（已验证的留存设计）：

- 6个部位：**武器**（攻击）、**护甲**（防御）、**战靴**（攻速）、**头盔**（暴击率）、**护符**（暴击伤害）、**戒指**（生命），每件都有自己的手绘图标（6×6=36种）。
- 品质：白→蓝→紫→橙→金→红（屠龙神兵级），副属性0–5条；同品质重复强化+1（+2%）；低品质分解成碎片，100个合成高一级；换装继承强化；保底50件必金、150件必红（第6章起）。
- 装备会改变外观：武器紫色以上两侧出现浮游法器、弹道按品质变成光矢/冰晶箭/奥术飞弹/火球/圣光星矢/雷霆长枪；战靴品质决定脚下光环；护甲、戒指、头盔高品质有光晕、护环、鹰眼瞄准线。
- 贡献值＝成长分E×有效行为（存活、技能、大招、躲危险区、巨弩发射、送礼），四个职业天然公平；经验＝贡献值，战斗中实时升级。
- 场上最多30人，其余进后援照样领奖；离开回来补发错过的关。

## 画面

- 竖屏 720×1280。上方熔岩洞窟里的巨龙，下方石板战场分三条航道，航道之间是符文石线，底部两角散着龙的宝藏。
- 顶栏：章节关卡、BOSS血条 + **破甲条**、本关倒计时；下面一行是士气条、全队BUFF和**本章祝福**。
- 底部：左战力榜（前三固定，带王冠），右玩法轮播（怎么玩 / 弹幕指令 / 屠龙巨弩 / 神殿祝福 / 礼物 / 四大职业 / 装备 / 榜单）。
- 主播可以用鼠标点战力榜里的人或画面里的英雄，查看装备属性卡。

## 存档

存在这台电脑、这个浏览器的**本地数据库（IndexedDB）**里（和星舰弹幕战分开存），每个玩家单独一条、每次只写有变化的人，几千人的存档也不卡；数据库打不开的极少数浏览器自动退回 localStorage。设置面板会显示存档大小和上次保存时间，写入失败会在画面上提示。设置面板可以导出 / 导入 / 清空。用 OBS「浏览器」源直播的主播用「复制存档文本」「粘贴文本导入」。

## 部署（Cloudflare Pages）

纯静态，不用构建：Pages 项目连接 `kaleomi/games`，**根目录填 `dragon-raid`**，构建命令留空，输出目录 `/`。

## 已知限制

- 抖音对「挂机直播」有规则，游戏可以不需要主播操作，但直播间最好仍有人出镜，上线前确认平台规则。
- 数值是按星舰弹幕战的难度曲线调的（10人20分钟模拟：大约在第3~4章巨龙前后卡关），巨弩和祝福让爱互动的直播间走得更远；上线后按实际数据再调 `src/config.js`。
