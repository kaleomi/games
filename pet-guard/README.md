# 萌宠保卫战（pet-guard）

抖音直播弹幕互动 · 养成系守护游戏，画风治愈。**观众自己领养萌宠，一起守护心愿树；主播可以挂机。**

故事：云朵小镇中央有一棵心愿树，结满了大家的心愿果。「坏心情」变成灰扑扑的小怪来偷果子、让小镇变灰。观众领养萌宠保护心愿树。坏心情不会被打死，而是被**净化**——从灰扑扑的生气样子变回彩色、笑着飘走；萌宠也不会死，体力打空就**累趴睡着**，打个盹再醒来。心愿果掉光了才算失败。

## 本地运行（不用部署）

- **Windows**：双击 **`启动游戏.bat`**（用系统自带的 PowerShell 在 `http://localhost:8080/` 开本机网页服务器并打开浏览器；端口被占就换 8081……）。
- **macOS / Linux**：终端运行 `./start.sh`。

和部署到 Cloudflare 的效果一样，熙梦照样能连。存档跟着网址走（`localhost` 和线上网址是两份），要搬用设置里的导出 / 导入。

## 主播怎么用

1. 打开熙梦并连接直播间（默认端口 8765，和星舰远征、群侠伏魔录一样）。
2. 用 Chrome 或 Edge 打开网址，浏览器问「访问本地网络」时点**允许**。
3. 按 **F2**（或右侧中间的 ⚙）打开设置：连接状态、补位流浪萌宠、音乐音效、礼物对照、测试按钮、存档、跳关。
4. 直播伴侣 / OBS 里用**窗口捕获**，直播前把设置面板收起。同一时间只能开一个游戏页面。
5. 浏览器要求先点一下页面才出声。

## 观众玩法

| 弹幕 | 效果 |
|---|---|
| 物种名：狗 / 猫 / 兔 / 熊猫 / 狐狸 / 仓鼠 / 企鹅 / 龙（也认「领养猫」「换企鹅」「柴柴」「团团」等） | 领养这种萌宠（第一次先出一颗蛋，晃一晃孵出来）；已经在场就是换成这只。每种萌宠各自养，换来换去不丢 |
| 加入 / 来了 / 领养 | 用上次那只上场（第一次来自动补缺：前排、治疗优先） |
| 摸摸（也认 摸、rua、撸、贴贴、抱抱） | 萌宠开心地蹦一下、回一点体力、亲密度+1（30秒一次，每天最多+20） |
| 起名 小黄（也认 取名、改名） | 给当前萌宠起名字（最多6个字），名字一直挂在头上、上榜单 |
| 大招（也认各萌宠大招名） | 放大招，冷却45秒 |
| 1 / 2 / 3 | **躲雨**：精英、首领出招前，地上分成三块标大号数字，绿牌安全、红牌危险，8秒后落下；发安全那块的数字就跑过去 |
| 撑伞（也认 伞、挡、拦截） | 首领放全屏大招时全员发，每次削弱1.5%，最多70%（全屏躲不开，只能挡） |
| 闪 | 冲出去一段，半秒无敌，躲弹幕和近身攻击 |
| 我的 / 装备 | 右下角弹出萌宠卡：形态、等级、天赋、亲密度、战力、四件装扮 |
| 签到 | 每天一次，领一件装扮（抽两次取好）+ 亲密度 |
| 排行 | 看自己在萌宠战力榜第几名 |
| 点赞 | 全场点赞满500：全队伤害+10% 15秒，心愿树长回一个果子 |

普攻、走位、技能全自动；只有大招、躲雨、撑伞、闪需要发弹幕（送礼开了「自动守护」就全自动）。

## 关卡

- **五个场景轮换**：春日花园（首领暴雨云大王）→ 夏日海边（暴躁河豚）→ 秋日果园（失眠猫头鹰）→ 冬日雪原（孤单雪怪）→ 星空梦境（坏心情魔王）；第6章起第二轮，更难。
- **每章5关**：1–3关清小怪，二十几秒后出「头目」，净化它过关；第4关精英；第5关首领。限时2分钟（首领关2分半）。
- **心愿树**：画面底部，树上12个心愿果就是血量。坏心情走到树下会打树；**偷果鼠**不打萌宠、专门溜去偷果子（头上有「！」），偷到就往回跑——跑掉之前净化它，果子会还回来。嘀咕鸦会俯冲啄树。全屏大招也会吹掉果子（撑伞挡得越多掉得越少）。
- **失败**（果子掉光或超时）：回到本章第一关重新守，等级、天赋、装扮都在。
- **小怪**：灰灰团、小乌云（远程下雨）、偷果鼠、刺刺栗（皮厚，近身打它会被扎）、泪泪泡（打空先哭成两个小的）。**精英**：起床气熊（枕头大砸，砸中会晕）、闹钟怪（起床铃，横条）、嘀咕鸦（会飞，乱啄一通）。
- **首领**有三个阶段（血量66%、33%），弹幕越来越密；躲雨区域分四种样子（三圈、扇面、横条、三个圈），都标 1 2 3；第二阶段起有全屏大招（只能撑伞）；失眠猫头鹰的瞌睡雾会让萌宠睡着几秒，孤单雪怪的暴风雪会冻住。

## 养成

- **长大**：幼崽 → Lv8 少年 → Lv20 成年，换形态时屏幕中间放「长大了！」。等级不封顶，每级攻击体力+2%。新领养的萌宠从「自己最高那只的一半等级」开始。
- **天赋**（礼物加油鸭「天赋觉醒」，随机一档、取最好，越往后越难出）：平凡 ×1 → 出色 ×1.4 → 卓越 ×1.8 → 非凡 ×2.2 → 传奇 ×2.6 → 神话 ×3；200次必出神话；神话之后继续升星（同群侠伏魔录的武神骨）。非凡以上脚下有光环，传奇加金星，神话彩虹光环。
- **闪光**：每次觉醒有一点机会（150次保底）变成异色闪光萌宠，永久换色 + 一直闪星星，全属性×1.1。
- **亲密度**：摸摸 +1、投喂 +2、签到 +2；每过一档全属性 +2%（10档）。
- **装扮**（每只萌宠自己一套）：头饰（攻击）、项圈（体力）、围巾（防御）、玩具（暴击），品质 普通 → 精良 → 稀有 → 史诗 → 传说 → 梦幻；**头饰真的戴在萌宠头上**，品质越高越华丽。同品质再掉强化+1，低品质变碎片（100个合成高一级）。四件都稀有：技能+30%、冷却-15%；四件都史诗：大招+40%、冷却-10秒。
- **掉落**：送礼的排前面，再按贡献；小关第1名必掉，精英关、首领关前三必掉。保底：50件必出传说，第6章起150件必出梦幻。

## 美术素材（GPT 生成）

所有角色、道具、背景都用 GPT 生成，提示词在 `art/PROMPTS.md`（`art/prompts.json` 是源，改完跑 `node tools/build_prompts.mjs` 重新生成）。

生成好的原图按清单里的文件名命名（`pet_shiba.png`、`foe_dust.png`、`bg_spring.png`……），放进一个文件夹，然后：

```
python3 tools/import_art.py 原图文件夹 --preview 预览文件夹
```

脚本会：白底抠图（从边缘往里灌，主体有描边所以里面的白毛不会被抠掉；灰色地面阴影一起去掉）、黑底发光图按亮度转透明、按设定图的行列切开（三个成长阶段 / 生气和开心两态 / 网格图标）、裁边缩放、存成 WebP 放进 `assets/`，并更新 `assets/manifest.json`。游戏只加载清单里有的图，**缺的图用占位图形代替，换上真图不用改代码**。单张图要修正（萌宠朝左了要翻转、阴影太深要放宽容差、切出来顺序不对）写在 `art/fix.json`：

```json
{ "pet_cat": { "flip": true }, "foe_burr": { "bgTol": 34 }, "eggs": { "order": [0,1,2,3,7,6,5,4] } }
```

萌宠的动作（呼吸、蹦跳、扑击、受击压扁、翻滚、打盹、孵化、长大闪光、净化飘走）都是程序做的，一张图就够；想要更灵动可以加序列帧（`seq_<物种>_idle.png` 等，一排4帧），导入后自动替换。头饰、墨镜戴的位置在 `src/render.js` 的 `WEAR` 表里按物种微调。

背景音乐可选：`bgm_lobby / bgm_battle / bgm_boss / bgm_win` 的 mp3 放进原图文件夹一起导入；没有就只放合成的小音效。

## 数值

全部在 `src/config.js`：萌宠基础属性和招式（`SPECIES`、`KIT`、`PASSIVE`）、成长形态（`FORMS`）、天赋（`TALENT`）、亲密度（`BOND`）、装扮（`GEAR`）、关卡与首领血量（`STAGE`、`CHAPTERS`）、坏心情（`FOES`、`ENEMY`）、心愿树（`TREE`）、礼物（`GIFTS`）。

无画面模拟：`node tests/progress.mjs 种子 人数 小时 反应率`（不送礼的情况下：8–15人1小时大约打到第6章，4人在第4章会卡住，要靠升级和礼物冲过去）；`node tests/sim.mjs 种子 只数 分钟 起始关 等级`。

## 开发

- 纯静态，无需构建；`npm test` 跑单元测试（Node 20+）；`python3 tests/shot.py 输出目录` 用无头浏览器截几张图看看画面。
- 熙梦连接（`src/relay.js`）、存档（IndexedDB，`src/idb-store.js`）、礼物计数、后援、补位、战力榜的写法和群侠伏魔录一致。
