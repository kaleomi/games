# 萌宠保卫战（pet-guard）

抖音直播弹幕互动 · 养成系守护游戏，画风治愈。**观众自己领养萌宠，一起守护心愿树；主播可以挂机。**

故事：云朵小镇中央有一棵心愿树，结满了大家的心愿果——**每个果子都可以挂上一位观众的真实心愿**。「坏心情」变成灰扑扑的小怪来偷果子、让小镇变灰。观众领养萌宠保护心愿树。坏心情不会被打死，而是被**净化**——从灰扑扑的生气样子变回彩色、笑着飘走；萌宠也不会死，体力打空就**累趴睡着**，打个盹再醒来。心愿果掉光了才算失败。

## 和别的弹幕游戏不一样的地方

骨架（主播挂机、熙梦接入、章节闯关、躲雨1/2/3、装扮、天赋、后援、存档）沿用群侠伏魔录验证过的那一套，但核心玩法换成了只属于「养成 + 治愈」的几样：

| 新玩法 | 说明 |
|---|---|
| 许愿果 | 观众发「许愿 考研上岸」，心愿就挂到心愿树的一个果子上（系着粉丝带，树上轮流冒气泡念出来）。心愿果就是血量，**偷果鼠优先偷挂着心愿的果子**，头上顶着「某某的心愿」往外跑；谁家萌宠在它跑掉前净化它，心愿挂回树上，**抢回来的人和许愿的人友情+3**。跑掉了心愿就丢了，要重新许。挂满12个就排队，存档记着，刷新页面不丢。 |
| 抱抱首领 | 首领打空**不消失，而是委屈大哭**：小怪全都被感动、弹幕收掉，全场发「抱抱」（点赞也算）安慰它，需要的抱抱数按在场真人算。5秒内安慰好评S、9秒内A、14秒内B，超时它自己慢慢好起来（C，照样过关）。评S时抱得最多的人多拿一件装扮；首领变成小精灵跟着抱得最多那只萌宠。不计时，主播挂机时流浪萌宠也会慢慢抱。 |
| 心愿成真 | 首领被安慰好后，树上亮着的心愿全都变成天灯，带着名字和心愿飞上天；许愿人的萌宠拿经验和亲密度，个人记「心愿成真」次数，结算页显示这次成真了几个。 |
| 点赞撑伞 | 首领蓄力全屏大招时，**全场点赞**给心愿树撑起一个粉色护罩（每个赞+0.12%，每人每秒最多算15个，最多挡70%），点赞的萌宠举起小伞；发「撑伞」也照样算。顺便给直播间刷赞。 |
| 好朋友 | 发「贴贴」，自己的萌宠跑过去抱一下在场的好朋友（没有就抱最近的别人家萌宠），两人友情+1（同一对每天最多+10）。友情**跨直播保存在双方存档里**：3 好朋友 → 12 好伙伴 → 30 最佳拍档 → 60 灵魂伙伴。好朋友同时在场，会自动放**友情合体技**（两道爱心光汇到坏心情堆里炸开、两只各回体力），横幅写着两个人的名字；等级越高越强。 |
| 收服小精灵 | 净化坏心情有机会收服它（小怪1.2%、偷果鼠4%、精英15%、首领给抱得最多的人）：开心版的小精灵跟在萌宠身后飘。图鉴13种，每多一种全属性+1%；跟着的那只另有加成（越稀有越强）。 |
| 鲜花种花 | 送鲜花除了叫小伙伴、放大招，还在送礼人萌宠旁边**种花**（一个礼物一朵，一次最多3朵）：花开后给旁边的萌宠慢慢回血、让走近的坏心情慢下来。整章都在，越送战场越像花园，换季清空。 |

## 本地运行（不用部署）

- **Windows**：双击 **`启动游戏.bat`**（用系统自带的 PowerShell 在 `http://localhost:8080/` 开本机网页服务器并打开浏览器；端口被占就换 8081……）。
- **macOS / Linux**：终端运行 `./start.sh`。

和部署到 Cloudflare 的效果一样，熙梦照样能连。存档跟着网址走（`localhost` 和线上网址是两份），要搬用设置里的导出 / 导入。

## 主播怎么用

1. 打开熙梦并连接直播间（默认端口 8765，和星舰远征、群侠伏魔录一样）。
2. 用 Chrome 或 Edge 打开网址，浏览器问「访问本地网络」时点**允许**。
3. 按 **F2**（或右侧中间的 ⚙）打开设置：连接状态、补位流浪萌宠、音乐音效、**心愿树（心愿文字上不上屏、屏蔽词、清空）**、礼物对照、测试按钮（含全员许愿、贴贴、首领直接哭、全员抱抱）、存档、跳关。
4. 直播伴侣 / OBS 里用**窗口捕获**，直播前把设置面板收起。同一时间只能开一个游戏页面。
5. 浏览器要求先点一下页面才出声。

## 观众玩法

| 许愿 考研上岸（也认「许个愿」「心愿」） | 把心愿挂上心愿树（最多10个字，每人一个，再许就是改写；15秒一次） |

| 加入 / 来了 / 领养 | 用上次那只上场（第一次来自动补缺：前排、治疗优先） |
| 摸摸（也认 摸、rua、撸） | 萌宠开心地蹦一下、回一点体力、亲密度+1（30秒一次，每天最多+20） |

| 大招（也认各萌宠大招名） | 放大招，冷却45秒 |
| 1 / 2 / 3 | **躲雨**：精英、首领出招前，地上分成三块标大号数字，绿牌安全、红牌危险，8秒后落下；发安全那块的数字就跑过去 |
| 撑伞（也认 伞、挡、拦截） | 首领放全屏大招时发，每次削弱1.5%，最多70%（全屏躲不开，只能挡）；**点赞也能撑护罩** |
| 闪 | 冲出去一段，半秒无敌，躲弹幕和近身攻击 |

普攻、走位、技能全自动；只有大招、躲雨、撑伞、闪、抱抱需要发弹幕（送礼开了「自动守护」就全自动，连抱抱也会自动）。

## 关卡

- **五个场景轮换**：春日花园（首领暴雨云大王）→ 夏日海边（暴躁河豚）→ 秋日果园（失眠猫头鹰）→ 冬日雪原（孤单雪怪）→ 星空梦境（坏心情魔王）；第6章起第二轮，更难。
- **每章5关**：1–3关清小怪，二十几秒后出「头目」，净化它过关；第4关精英；第5关首领。限时2分钟（首领关2分半）。
- **心愿树**：画面底部，树上12个心愿果就是血量。坏心情走到树下会打树；**偷果鼠**不打萌宠、专门溜去偷果子（头上有「！」），偷到就往回跑——跑掉之前净化它，果子会还回来。嘀咕鸦会俯冲啄树。全屏大招也会吹掉果子（撑伞挡得越多掉得越少）。
- **失败**（果子掉光或超时）：回到本章第一关重新守，等级、天赋、装扮都在。
- **小怪**：灰灰团、小乌云（远程下雨）、偷果鼠、刺刺栗（皮厚，近身打它会被扎）、泪泪泡（打空先哭成两个小的）。**精英**：起床气熊（枕头大砸，砸中会晕）、闹钟怪（起床铃，横条）、嘀咕鸦（会飞，乱啄一通）。
- **首领**有三个阶段（血量66%、33%），弹幕越来越密；躲雨区域分四种样子（三圈、扇面、横条、三个圈），都标 1 2 3；第二阶段起有全屏大招（点赞撑护罩 / 发撑伞）；失眠猫头鹰的瞌睡雾会让萌宠睡着几秒，孤单雪怪的暴风雪会冻住。坏心情打空后委屈大哭，抱抱安慰好才过关（见上面「抱抱首领」）。

## 养成

- **长大**：幼崽 → Lv8 少年 → Lv20 成年，换形态时萌宠就地发光、变大一下，顶部横幅播报（不弹窗挡战场）。等级不封顶，每级攻击体力+2%。新领养的萌宠从「自己最高那只的一半等级」开始。
- **天赋**（礼物加油鸭「天赋觉醒」，随机一档、取最好，越往后越难出）：平凡 ×1 → 出色 ×1.4 → 卓越 ×1.8 → 非凡 ×2.2 → 传奇 ×2.6 → 神话 ×3；200次必出神话；神话之后继续升星（同群侠伏魔录的武神骨）。非凡以上脚下有光环，传奇加金星，神话彩虹光环。
- **闪光**：每次觉醒有一点机会（150次保底）变成异色闪光萌宠，永久换色 + 一直闪星星，全属性×1.1。
- **亲密度**：摸摸 +1、投喂 +2、签到 +2、心愿成真 +3；每过一档全属性 +2%（10档）。
- **好朋友 / 小精灵**：见上面的新玩法表；萌宠卡上显示最好的朋友和跟着的小精灵（图鉴几种）。
- **装扮**（每只萌宠自己一套）：头饰（攻击）、项圈（体力）、围巾（防御）、玩具（暴击），品质 普通 → 精良 → 稀有 → 史诗 → 传说 → 梦幻；**头饰真的戴在萌宠头上**，品质越高越华丽。同品质再掉强化+1，低品质变碎片（100个合成高一级）。四件都稀有：技能+30%、冷却-15%；四件都史诗：大招+40%、冷却-10秒。
- **掉落**：送礼的排前面，再按贡献；小关第1名必掉，精英关、首领关前三必掉。保底：50件必出传说，第6章起150件必出梦幻。

## 美术素材（GPT 生成）

所有角色、道具、背景、序列帧都用 GPT 生成，**已经全部导入**（`assets/`，78张原图 → 140张贴图 + 32组序列帧，约14MB）。提示词在 `art/PROMPTS.md`（`art/prompts.json` 是源，改完跑 `node tools/build_prompts.mjs` 重新生成）。想换哪张，重新生成后单独导入就行：`python3 tools/import_art.py 原图文件夹 --only pet_cat`。

生成好的原图按清单里的文件名命名（`pet_shiba.png`、`foe_dust.png`、`bg_spring.png`……），放进一个文件夹，然后：

```
python3 tools/import_art.py 原图文件夹 --preview 预览文件夹
```

脚本会：白底抠图（从边缘往里灌，主体有描边所以里面的白毛不会被抠掉；灰色地面阴影一起去掉）、黑底发光图按亮度转透明、按设定图的行列切开（三个成长阶段 / 生气和开心两态 / 网格图标）、裁边缩放、存成 WebP 放进 `assets/`，并更新 `assets/manifest.json`。游戏只加载清单里有的图，**缺的图用占位图形代替，换上真图不用改代码**。单张图要修正（萌宠朝左了要翻转、阴影太深要放宽容差、切出来顺序不对）写在 `art/fix.json`：

```json
{ "pet_cat": { "flip": true }, "foe_burr": { "bgTol": 34 }, "eggs": { "order": [0,1,2,3,7,6,5,4] }, "gear_hat": { "holes": 600 } }
```

`holes`：把被主体围住的白底小洞也抠掉（花环头饰、绳编项圈中间那块白），数字是洞的最小面积（像素）。白底容差默认很紧（8），白兔子的白毛不会被吃掉。发光特效图（`fx_glow`，黑底）按网格切，不按连通块切。

萌宠的动作（呼吸、蹦跳、扑击、受击压扁、翻滚、打盹、孵化、长大闪光、净化飘走）是程序做的；有序列帧的会叠上序列帧（`seq_<物种>_<idle|attack|happy|sleep>[_<形态>].png`，一排4帧，睡觉2帧），待机按「眨眼—摆动」节奏播放，攻击按出招进度播放。头饰、墨镜戴的位置在 `src/render.js` 的 `WEAR` 表里按物种微调。

新玩法的图**也已导入**：`flowers`（4朵花，种花用）、`lantern`（心愿天灯）、`sad_storm / sad_puffer / sad_owl / sad_yeti / sad_king`（首领委屈大哭版，生成时把原来的首领图一起发给 GPT）。缺哪张就用简单图形 / 生气版加眼泪顶着，不影响玩。

**音效**：全部换成真实录音（手鼓、铃铛、风铃、木琴、竖琴、小提琴、口哨、长号、收银机……），放在 `assets/sfx/`，来源和授权（CC0 / CC-BY 3.0）见 `assets/sfx/CREDITS.md`。木琴、竖琴、小提琴是一个个真实音符，升级、许愿、过关的小旋律用它们拼出来，不再有电子合成音。
