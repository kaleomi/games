# 星舰远征（starship-barrage，原名「星舰弹幕战」）

> **改名说明（2026-10-27）**：抖音开放平台规定玩法名称不能带「弹幕」，玩法名改成「星舰远征」（页面标题、开局Logo、设置面板、存档文件名都改了；代码目录和本地数据库名不变，旧存档照常读）。同时按平台《直播玩法安全用词规避枚举表》改了画面上主播和观众能看到的字：不出现「游戏」「玩家」「冷却」「BUFF」等词（大招写成「每45秒一次」、冷却中写「还要N秒」，「弹幕指令」页改叫「评论指令」，战鼓的「弹幕雨」改叫「流星雨」）。

抖音直播弹幕互动游戏，两种模式随时切换。**观众自己当飞行员，主播不用操作。**

> **目前对战（红蓝对抗）模式暂时关闭，只开讨伐**：打开页面直接是讨伐，观众发「换对战」只提示暂未开放，设置里的切换按钮也隐藏了。要恢复就把 `src/config.js` 里的 `PVP_ENABLED` 改成 `true`。

- **对战**：红蓝两支舰队对攻，打掉对面旗舰核心获胜。
- **讨伐**：全员一支舰队（输出舰 / 重装机甲 / 医疗舰 / 蜂巢航母四选一），**每章5关**（1–3关虫群+精英头目、第4关精英、第5关首领）；放大招、躲红色区域、过关掉装备。**每关限时2分钟**，失败退回上一章第1关。场上最多30人，其余进后援照样领奖。关卡进度、职业和装备都存档。

和暴力摩托一样，观众发「换讨伐」「换对战」投票切换，在场一半人（含）同意就立刻换，开一局新的；设置面板里主播也能直接切。

观众发弹幕加入后，头像变成一架战机，由AI自动驾驶、躲弹、开火；观众用弹幕下战术指令，用礼物召唤弹幕阵型、战舰和旗舰主炮。打掉对面旗舰核心的一方获胜。

## 主播怎么用

1. 先打开熙梦并连接直播间（和凌霄守山一样，默认端口 8765）。
2. 用 Chrome 或 Edge 打开部署好的 **https://** 网址。浏览器问「访问本地网络 / 本机应用」时点 **允许**。
3. 页面会自动连熙梦。按 **F2**（或点右侧中间的 ⚙）打开设置面板，可以看连接状态、改端口和参数。
4. 游戏窗口单独放一个窗口，在直播伴侣 / OBS 里用 **窗口捕获**，不要最小化。直播前把设置面板收起。
5. 建议在 Chrome「设置 → 性能」里把游戏网址加入「始终让这些网站保持活动状态」。
6. 同一时间只能开一个游戏页面；再开第二个会提示关闭，避免同一份礼物结算两次。

设置面板里改完会自动保存、马上生效（顶部也有「保存设置」按钮）。**默认：背景音乐开（程序合成的太空电子乐，战斗中鼓点更密，可调音量）、音效开、语音播报关、补位NPC 4架**；浏览器要求先在页面上点一下鼠标才会出声。「讨伐礼物对照」里可以追加礼物（每行「礼物名=效果」，效果填 经验/佣兵/战鼓/英雄/双倍/宝箱），对战模式的礼物分档收在下面的折叠项里。「人少时补位NPC到 N 架」：真人不够 N 个时自动补灰色 NPC 凑数，对战每队各补、讨伐只补我方舰队，填 0 不补。

没连熙梦时，设置面板里的「测试」按钮可以加测试观众、模拟1–5档礼物、拦截和点赞（测试观众不写入存档）。连上熙梦后测试按钮自动禁用。

## 卡密门禁（一机一卡密）

星舰远征的网页版按月卖卡密，授权站是 <https://game-live.xialuoxi.com>（代码在 kaleomi/game-license）。

- 没有有效卡密时，打开游戏网址只能看到卡密页，游戏网页和脚本都拿不到（Cloudflare 上拦截，不是页面上盖一层）。
- 卡密第一次输入时绑定这台电脑的浏览器（卡密页上显示机器码）。换电脑、换浏览器、清理浏览器数据都要找客服在授权站后台换绑。
- 游戏开着时每 15 分钟自动续签；到期后本场还能用 3 小时（左上角提示），之后盖上卡密框要求续费；被停用或换绑走会立刻盖上卡密框。
- 代码：`functions/_middleware.js` + `license/gate.js`（Cloudflare Pages 的门禁，所有请求先经过它）、`license-keeper.js`（页面里的续签和到期提示）。
- 改门禁代码要改 kaleomi/game-license 的 `client/` 再复制过来，三款游戏共用同一份。

## 讨伐模式

我方没有要塞，阵亡判定只看舰队：全员同时阵亡就失败（战机阵亡10秒后复活）。

### 四种战舰（发名字选择 / 切换，存档记住；发「加入」自动补缺的职业）

**机甲普攻是近战**：300像素内有异形就冲上去砍一刀（2.6倍攻击的范围斩，顺带砍掉附近的敌弹，主炮多管加成同样生效），砍完退回本航道；附近没怪、BOSS在场时，**冲到BOSS身下近战砍核心和附近炮台**（这一趟带短暂护体，不会一冲上去就被弹幕打死），砍完再退回。

**所有攻击都自动索敌**：普攻朝最近的敌人打（附近没有异形时打母舰核心），子弹会追踪目标、飞成弧线；医疗舰和机甲也一直普攻。导弹、无人机、光束、礼物弹幕同样自动追踪。（对战模式不变。）

**小技能每10秒自动释放**；大招要观众发「大招」（也认技能名「光束」「冲锋」「圣光」「蜂群」），冷却45秒、开局就绪；冷却快好（2秒内）时发的「大招」会排队，好了自动补放。战机右边两个小图标是小技能和大招的冷却。NPC 补位战机的大招自动放。

| 战舰 | 血量 / 攻击 | 小技能（自动，冷却10秒） | 大招「大招」（冷却45秒，开局就绪） |
|---|---|---|---|
| 输出舰 | 100 / 10 | 集束导弹：8枚追踪导弹，每枚2.5倍攻击 | 歼灭光束：蓄能0.5秒后发射2.5秒光束，**自动瞄准**最近的异形（没有就瞄母舰触手炮/核心），光束扫过的敌人每秒12倍攻击 |
| 重装机甲 | 260 / 5，减伤35% | 冲击：前冲一拳，朝最近的敌人打出扇形冲击波（8倍攻击）击退虫群、打散敌方子弹，嘲讽3秒 | 无敌冲锋斩：无敌4秒，冲进怪最多的地方（没有就冲母舰触手炮/核心）旋风斩，每0.2秒4倍攻击，结束飞回航道 |
| 蜂巢航母 | 150 / 6，减伤15% | 无人机：放4架攻击无人机追着怪打8秒 | 蜂群风暴：10架护卫无人机在舰队区巡逻8秒，撞到敌方子弹就拦下，顺便开火 |
| 医疗舰 | 90 / 4，减伤10% | 治疗链：同时给血量比例最低的3艘回血（30+28%最大血量） | 生命圣光：先复活阵亡队友（50%血），之后**5秒内持续给全体回血**，每秒10%最大血量（共50%） |

机甲站最前排、输出居中、航母和医疗在后排；每艘战机在自己的航道里慢慢随机游走。引擎装备的「技能急速」同时缩短小技能和大招冷却。

每个技能都有动作和特效：输出舰导弹齐射后坐 + 尾烟、光束蓄能聚光再跟着目标转；机甲前冲一拳 + 冲击波、冲锋时残影 + 金色无敌护体 + 双刃旋风；医疗舰放技能时机身一鼓 + 绿色波纹 + 治疗链，大招全屏光环 + 每艘船头顶落下光柱；航母放飞无人机，护卫蜂群拦子弹时闪光。**大招颜色跟着这艘战舰的锻造品质走**：普通银白、精良蓝、史诗紫、传说橙、神话金、至尊红（外圈再加一层彩虹流光）——光束、蓄能粒子、机甲护体和旋风刃、圣光光柱和回血波纹、护卫蜂群全换成品质色；品质越高光束越粗、能量环越多，传说以上释放瞬间多一圈冲击环，神话/至尊光束两侧飘星屑、机甲外圈多一道转动光环；横幅写成「释放「传说·歼灭光束」」（只是画面，伤害范围不变）。点赞充能，满了打出一发穿透超载炮（8倍攻击）。

### 红色区域（敌方技能）

虫群里的炮虫和母舰会放技能：被锁定的航道（左/中/右）**整条**变成红色区域（从顶栏一直到底部面板），**10秒倒计时**。发「左」「中」「右」换航道躲开；同一时间最多锁两条，总有一条安全。

| 技能 | 来源 | 伤害（最大血量比例） |
|---|---|---|
| 酸液轰炸 | 炮虫，单航道 | 60% |
| 母舰炮击 | 母舰，单航道 | 70% |
| 双线扫射 | 母舰半血后，两条航道 | 65% |
| 湮灭炮 | 母舰三分之一血以下，两条航道 | 110%，全员发「拦截」最多削弱60% |

章越高伤害越高（每章+4%）。**机神附体（付费BUFF）**：送礼后每1抖币12秒，**不设上限、可累积**，只在讨伐开战时扣时间，跟着抖音账号存档（刷新页面不丢）。期间**自动躲子弹、自动躲红区技能、自动放技能和大招**（大招看时机放，就绪3秒还没好时机也直接放）；**主播刷新页面后，还有机神附体时间、最近3小时来过的观众会自动上场**（不用再发弹幕）；有机神附体时自动战斗，不会因为5分钟没互动进后援。战机**名字上方**显示「⚡机神附体 m:ss」剩余时间，「我的」卡片也能看。不送礼要自己发「左/中/右」躲、发「大招」放大招。NPC 补位战机会慢几秒再躲。

### 贡献值与装备

- **贡献值 ＝ 成长分E × 有效行为**（不再按伤害/治疗/承伤算，四个职业天然公平）：
  - **E** 由等级和身上装备决定：E = 1 + 0.02×(等级−1) + 0.02×装备总评分（新人约1，紫橙Lv20约2，一身红Lv60约6）；临时BUFF不影响E；每次行为按当时的E算，之后升级不追溯。「装备」卡片上能看到自己的E。
  - 在场存活每5秒 **+1E**；技能成功释放 **+6E**；大招 **+12E**；**躲开红区 +3E**（红区预警时人在里面、命中时躲出去了，手动和自动躲都算）；送礼 **新增抖币×E**，只算一次。
  - **医疗保底**：没人掉血时，治疗链改成给3个护盾最少的队友各加10%最大血量的护盾（上限30%），照样算一次有效技能；四个职业贡献基本持平（10人模拟：每关每人 44/45/43/44）。
  - 冷却中、没放出去的技能不算；礼物触发的技能/大招、佣兵和召唤物不重复算；打怪伤害、击杀不算。
  - 参考（10人不带装备）：虫群关每人约40–50，精英关约90，首领关约140。
- 过关掉装备，**掉落顺序先看本局礼物榜**：本局送过礼的排前面（送得多的在前，不显示金额），其余按贡献排；排前三必掉，其余60%概率；第1位抽两次取好的。**1–3关过得快（约1分钟），装备掉率×30%**；第4、5关正常掉率。

## 对战模式

- 打掉对面旗舰核心获胜；每局上限15分钟，到时比剩余血量。
- 翻盘设计：旗舰核心掉到一半以下，护盾回复加快并追加中央炮台；主炮可被拦截。
- **战功只按战果计算**（击落、旗舰伤害、炮台、战舰、拦截、胜利），不显示任何消费金额；送礼本身不加战功。
- **等级与经验**：经验＝获得的贡献值（讨伐）/战功（对战），每局另加20点参与经验；讨伐里贡献值每秒实时换成经验，战斗中就能升级（金色光环+「升级！Lv.N」，逢10级上横幅）。满100级，升级所需经验 = 200 + 60×等级 + 4×等级²。讨伐里每级攻击、生命+2%；对战里等级越高AI躲弹越灵活、血量越高。等级跟着抖音用户ID存档，升级解锁涂装。
- 名字旁边都显示等级：战机头顶、贡献榜、结算榜、「我的」「装备」卡片。
- 本周战功榜每周一清零。人少时自动补灰色「NPC」战机，NPC 不进榜单。
- 开局倒计时页面会一屏展示全部规则和礼物效果。

## 存档

存在这台电脑、这个浏览器的**本地数据库（IndexedDB）**里，别的主播读不到；容量比以前的 localStorage（约5MB，约3000人就满）大得多，几万个玩家也装得下。每个玩家单独一条，每5秒只保存有变化的玩家（在场的、后援的、刚领奖的），5000人的存档保存一次不到1毫秒，画面不会卡。第一次打开新版本会自动把旧存档搬过来。设置面板的存档一栏显示玩家数、大约多大、上次保存时间，写入失败会在画面上提示。设置面板可以导出（Chrome / Edge 会弹出「另存为」窗口，自己选保存位置和文件名）/ 导入（导入前自动备份）/ 清空（需两次确认）。不要清除这个网站的浏览数据；重要直播前后导出一次留底。

**用 OBS「浏览器」源直播的主播**：OBS 内置浏览器不支持下载/另存为文件（导出会得到 0KB 的空文件），而且它的存档和电脑上 Chrome 里的是两份。在 OBS 里右键源 →「交互」打开页面，按 F2 →「复制存档文本」（或点「导出存档」，检测到 OBS 会自动弹出存档文本），粘贴到记事本另存为 .json；还原时用「粘贴文本导入」。

## 部署（Cloudflare Pages）

Pages 项目连接 `kaleomi/games`，**根目录填 `starship-barrage`**，构建命令留空，**输出目录填 `dist`**。

`dist/` 是压缩后的网页版成品（游戏脚本打包成一个 `app.js`，样式和卡密续签脚本也压缩过），已经提交在仓库里，部署时不用构建。
`functions/`（卡密门禁）仍在 `starship-barrage/` 下，Pages 会自动带上。

改了 `src/`、`index.html`、`style.css`、`license-keeper.js` 之后要重新生成 `dist/` 再提交：

```
npm i                 # 第一次：装 esbuild
npm run build         # 生成 dist/
```

忘了重新生成的话 `npm test` 会报「dist/ 与源码一致」失败。
