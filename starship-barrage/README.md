# 星舰弹幕战（starship-barrage）

抖音直播弹幕互动游戏：竖屏红蓝舰队对攻。**观众自己当飞行员，主播不用操作。**

观众发弹幕加入后，头像变成一架战机，由AI自动驾驶、躲弹、开火；观众用弹幕下战术指令，用礼物召唤弹幕阵型、战舰和旗舰主炮。打掉对面旗舰核心的一方获胜。

## 主播怎么用

1. 先打开熙梦并连接直播间（和凌霄守山一样，默认端口 8765）。
2. 用 Chrome 或 Edge 打开部署好的 **https://** 网址。浏览器问「访问本地网络 / 本机应用」时点 **允许**。
3. 页面会自动连熙梦。按 **F2**（或点右侧中间的 ⚙）打开设置面板，可以看连接状态、改端口和参数。
4. 游戏窗口单独放一个窗口，在直播伴侣 / OBS 里用 **窗口捕获**，不要最小化。直播前把设置面板收起。
5. 建议在 Chrome「设置 → 性能」里把游戏网址加入「始终让这些网站保持活动状态」。
6. 同一时间只能开一个游戏页面；再开第二个会提示关闭，避免同一份礼物结算两次。

没连熙梦时，设置面板里的「测试」按钮可以加测试观众、模拟1–5档礼物、拦截和点赞（测试观众不写入存档）。连上熙梦后测试按钮自动禁用。

## 观众玩法

| 弹幕 | 效果 |
|---|---|
| 红 / 蓝 | 加入赤焰舰队 / 苍穹舰队（开战后不能换队，下局开始前可以换） |
| 激光 / 散弹 / 蓄力 | 换武器：激光射速快、散弹打战机强、蓄力弹穿透 |
| 左 / 中 / 右 | 换编队位置 |
| 核心 / 炮台 | 选攻击目标 |
| 拦截 | 对面主炮蓄力时削弱它，每次1.5%，最多60% |
| 我的 | 弹出自己的等级、战功卡片 |
| 点赞 | 给自己战机充能（每人每秒有上限），满了打出超载炮 |

## 礼物效果（按单个礼物价值，抖币，可在设置里改分档）

| 档位 | 默认价值 | 效果 |
|---|---|---|
| 1档 | 1–9 | 火力+1、护盾+1，25秒；每10个放一组环形弹幕 |
| 2档 | 10–49 | 弹幕阵型（螺旋 / 扇形） |
| 3档 | 50–199 | 激光网格或分裂弹 + 2架护卫僚机40秒 |
| 4档 | 200–999 | 召唤战舰50秒，舰体写着送礼人的名字（例如「大哥号」） |
| 5档 | 1000+ | 旗舰主炮：蓄力4秒，对面可拦截；同时多送的转成战舰 |

- 开战前（倒计时、结算时）送的礼物会记下来，开战后生效，不会丢。
- 也可以在设置里按礼物名指定档位（每行「礼物名=档位」）。
- 没带用户ID的礼物（神秘人）无法知道是哪队，只提示「请先发弹幕加入」，不会算到别人头上。

## 胜负、成长、榜单

- 打掉对面旗舰核心获胜；每局上限15分钟，到时比剩余血量。
- 翻盘设计：旗舰核心掉到一半以下，护盾回复加快并追加中央炮台；主炮可被拦截。
- **战功只按战果计算**（击落、旗舰伤害、炮台、战舰、拦截、胜利），不显示任何消费金额；送礼本身不加战功。
- 等级跟着抖音用户ID存档：等级越高，AI躲弹越灵活、战机血量越高；升级解锁涂装。
- 本周战功榜每周一清零。人少时自动补灰色「NPC」战机，NPC 不进榜单。
- 开局倒计时页面会一屏展示全部规则和礼物效果。

## 存档

存在这台电脑、这个浏览器的 localStorage 里。设置面板可以导出 / 导入（导入前自动备份）/ 清空（需两次确认）。不要清除这个网站的浏览数据；重要直播前后导出一次留底。

## 部署（Cloudflare Pages）

纯静态，不用构建：Pages 项目连接 `kaleomi/games`，**根目录填 `starship-barrage`**，构建命令留空，输出目录 `/`。

## 开发

```
node --test tests/*.test.js     # 15项逻辑测试（指令、分档、连击计数、去重、主炮拦截、存档、整局模拟）
python3 -m http.server 8811     # 本地预览 http://127.0.0.1:8811
```

| 文件 | 内容 |
|---|---|
| `src/config.js` | 全部数值（血量、伤害、礼物分档、经验） |
| `src/game.js` | 战斗模拟、AI躲弹、礼物效果、回合（不依赖页面，可在 Node 里测） |
| `src/relay.js` | 熙梦连接，沿用凌霄守山的 hello 协议、连击计数和去重 |
| `src/art.js` | 全部矢量美术（SVG）：三种机型×6涂装、红蓝两款旗舰、召唤战舰、炮台、僚机、子弹、勋章、徽章 |
| `src/render.js` | 竖屏画面、弹幕粒子、HUD（SVG 加载后栅格化缓存再绘制） |
| `src/ui.js` | 设置面板、开局规则页、结算页 |
| `src/save.js` | 玩家存档 |
| `src/audio.js` | 合成音效、中文语音播报 |

## 已知限制 / 下一步

- 抖音对「挂机直播」有规则，游戏可以不需要主播操作，但直播间最好仍有人出镜，上线前确认平台规则。
- 还没接抖音官方直播玩法接口，所以没有「小摇杆」王牌驾驶席；目前通过熙梦读取弹幕礼物。
- 人少时用NPC补位；单独的冷场PvE模式（大家一起打异形母舰）还没做。
