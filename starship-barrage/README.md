# 星舰弹幕战（starship-barrage）

抖音直播弹幕互动游戏，两种模式随时切换。**观众自己当飞行员，主播不用操作。**

- **对战**：红蓝两支舰队对攻，打掉对面旗舰核心获胜。
- **讨伐**：全员一支舰队（输出舰 / 重装机甲 / 医疗舰 / 蜂巢航母四选一），先清虫群，再打异形母舰；手动放技能、躲红色区域、打爆母舰掉装备。**每关限时2分钟**，全队阵亡或超时退回一关。关卡进度、职业和装备都存档。

和暴力摩托一样，观众发「换讨伐」「换对战」投票切换，在场一半人（含）同意就立刻换，开一局新的；设置面板里主播也能直接切。

观众发弹幕加入后，头像变成一架战机，由AI自动驾驶、躲弹、开火；观众用弹幕下战术指令，用礼物召唤弹幕阵型、战舰和旗舰主炮。打掉对面旗舰核心的一方获胜。

## 主播怎么用

1. 先打开熙梦并连接直播间（和凌霄守山一样，默认端口 8765）。
2. 用 Chrome 或 Edge 打开部署好的 **https://** 网址。浏览器问「访问本地网络 / 本机应用」时点 **允许**。
3. 页面会自动连熙梦。按 **F2**（或点右侧中间的 ⚙）打开设置面板，可以看连接状态、改端口和参数。
4. 游戏窗口单独放一个窗口，在直播伴侣 / OBS 里用 **窗口捕获**，不要最小化。直播前把设置面板收起。
5. 建议在 Chrome「设置 → 性能」里把游戏网址加入「始终让这些网站保持活动状态」。
6. 同一时间只能开一个游戏页面；再开第二个会提示关闭，避免同一份礼物结算两次。

设置面板里改完会自动保存、马上生效（顶部也有「保存设置」按钮）。「人少时补位NPC到 N 架」：真人不够 N 个时自动补灰色 NPC 凑数，对战每队各补、讨伐只补我方舰队，填 0 不补。

没连熙梦时，设置面板里的「测试」按钮可以加测试观众、模拟1–5档礼物、拦截和点赞（测试观众不写入存档）。连上熙梦后测试按钮自动禁用。

## 观众玩法

| 弹幕 | 效果 |
|---|---|
| 红 / 蓝 | 加入赤焰舰队 / 苍穹舰队（开战后不能换队，下局开始前可以换） |
| 激光 / 散弹 / 蓄力 | 换武器：激光射速快、散弹打战机强、蓄力弹穿透 |
| 左 / 中 / 右 | 换编队位置 |
| 核心 / 炮台 | 选攻击目标 |
| 拦截 | 对面主炮（讨伐模式是母舰湮灭炮）蓄力时削弱它，每次1.5%，最多60% |
| 我的 | 弹出自己的等级、战功卡片 |
| 换讨伐 / 换对战 | 投票换模式，在场一半人同意就换（也认「换PVE」「换打怪」「换PVP」等） |
| 点赞 | 给自己战机充能（每人每秒有上限），满了打出超载炮 |

## 礼物效果（按单个礼物价值，抖币，可在设置里改分档）

| 档位 | 默认价值 | 效果 |
|---|---|---|
| 1档 | 1–9 | 火力+1、护盾+1，25秒；每10个放一组环形弹幕 |
| 2档 | 10–49 | 弹幕阵型（螺旋 / 扇形） |
| 3档 | 50–199 | 激光网格或分裂弹 + 2架护卫僚机40秒 |
| 4档 | 200–999 | 召唤战舰50秒，舰体写着送礼人的名字（例如「大哥号」） |
| 5档 | 1000+ | 旗舰主炮：对战模式蓄力4秒、对面可拦截；讨伐模式轰掉母舰10%血量，母舰没出现时先蓄满等着。同时多送的转成战舰 |

- 讨伐模式下：任何礼物都按价值附带「自动躲弹」时间；1档改为火力+1、护盾+10%血量。
- 开战前（倒计时、结算时）送的礼物会记下来，开战后生效，不会丢。
- 也可以在设置里按礼物名指定档位（每行「礼物名=档位」）。
- 没带用户ID的礼物（神秘人）无法知道是哪队，只提示「请先发弹幕加入」，不会算到别人头上。

## 讨伐模式

我方没有要塞，阵亡判定只看舰队：全员同时阵亡就失败（战机阵亡10秒后复活）。

### 四种战舰（发名字选择 / 切换，存档记住；发「加入」自动补缺的职业）

技能要**观众自己打字放**：发「技能」放小技能，发「大招」放大招（也认技能名，如「导弹」「冲击」「回血」「无人机」「光束」「冲锋」「圣光」「蜂群」）。普通攻击自动。战机右边两个小图标亮起就是好了；冷却快好（2秒内）时发的指令会排队，好了自动补放；冷却中发会提示剩余秒数。NPC 补位战机自动放。

| 战舰 | 血量 / 攻击 | 小技能「技能」 | 大招「大招」（冷却45秒，开局就绪） |
|---|---|---|---|
| 输出舰 | 100 / 10 | 集束导弹：6枚追踪导弹，每枚2.5倍攻击，冷却6秒 | 歼灭光束：蓄能0.5秒后发射2.5秒光束，**自动瞄准**最近的异形（没有就瞄母舰触手炮/核心），光束扫过的敌人每秒12倍攻击 |
| 重装机甲 | 260 / 5，减伤35% | 冲击：前冲一拳，前方扇形冲击波（8倍攻击）击退虫群、打散敌方子弹，嘲讽3秒，冷却8秒 | 无敌冲锋斩：无敌4秒，冲进怪最多的地方（没有就冲母舰触手炮/核心）旋风斩，每0.2秒4倍攻击，结束飞回航道 |
| 蜂巢航母 | 150 / 6，减伤15% | 无人机：放4架攻击无人机追着怪打8秒，冷却8秒 | 蜂群风暴：10架护卫无人机在舰队区巡逻8秒，撞到敌方子弹就拦下，顺便开火 |
| 医疗舰 | 90 / 4，减伤10% | 治疗链：同时给血量比例最低的2艘回血（22+15%最大血量），冷却3秒；全员满血才开火 | 生命圣光：全体回40%血，复活阵亡队友（50%血） |

机甲站最前排、输出居中、航母和医疗在后排；每艘战机在自己的航道里慢慢随机游走。引擎装备的「技能急速」同时缩短小技能和大招冷却。

每个技能都有动作和特效：输出舰导弹齐射后坐 + 尾烟、光束蓄能聚光再跟着目标转；机甲前冲一拳 + 冲击波、冲锋时残影 + 金色无敌护体 + 双刃旋风；医疗舰放技能时机身一鼓 + 绿色波纹 + 治疗链，大招全屏光环 + 每艘船头顶落下光柱；航母放飞无人机，护卫蜂群拦子弹时闪光。点赞充能，满了打出一发穿透超载炮（8倍攻击）。

### 红色区域（敌方技能）

虫群里的炮虫和母舰会放技能：被锁定的航道（左/中/右）出现**红色区域，10秒倒计时**。发「左」「中」「右」换航道躲开；同一时间最多锁两条，总有一条安全。

| 技能 | 来源 | 伤害（最大血量比例） |
|---|---|---|
| 酸液轰炸 | 炮虫，单航道 | 60% |
| 母舰炮击 | 母舰，单航道 | 70% |
| 双线扫射 | 母舰半血后，两条航道 | 65% |
| 湮灭炮 | 母舰三分之一血以下，两条航道 | 110%，全员发「拦截」最多削弱60% |

关卡越高伤害越高（每关+4%）。**自动躲弹是付费专属**：送礼后每1抖币6秒，**不设上限、可累积**，只在讨伐开战时扣时间，跟着抖音账号存档（刷新页面不丢）；战机下方显示「躲 m:ss」剩余时间，「我的」卡片也能看。期间自动躲红区和子弹；不送礼要自己发指令躲。NPC 补位战机会慢几秒再躲。

### 贡献值与装备

- 贡献值 = 打出的伤害×0.1 + 给队友回血×0.55 + 替队友挨的伤害（减伤后）×0.6，过关全员+200。只看战斗表现，不显示消费金额。
- 打爆母舰掉装备：贡献前三必掉，其余60%概率；第一名抽两次取好的。比身上的好就自动穿上，否则分解成星核碎片（先存着，后面做强化用）。
- 四个部位：主炮（攻击）、装甲（血量）、引擎（技能急速）、核心（技能强度）。品质参考凌霄：普通 / 精良 / 传说 / 极品 / 七彩，属性倍率 1 / 2 / 4 / 8 / 12；关卡越高好装备越容易出。

### 关卡

| 阶段 | 内容 |
|---|---|
| 虫群 | 约21–30秒（随关卡变长）：小虫、自爆虫（先在目标处画锁定圈2.2秒再扑过来）、炮虫 |
| 母舰 | 四个触手炮可以打掉（40秒后再生）；按血量分三阶段，技能越放越快 |
| 结算 | 打爆母舰：进下一关、掉装备；全队阵亡或超时：退回一关 |

**每关限时2分钟**，从出击算起（含虫群），顶部显示本关剩余时间。第1关母舰20000血，每关×1.18。参考模拟（一半真人会躲红区，平均每人6秒发一次「技能」）：6人不送礼约1.5–1.9分钟打过第1关；第2关起6个人不送礼打不完，需要更多人、礼物或装备，12人可以打过第3关。

## 对战模式

- 打掉对面旗舰核心获胜；每局上限15分钟，到时比剩余血量。
- 翻盘设计：旗舰核心掉到一半以下，护盾回复加快并追加中央炮台；主炮可被拦截。
- **战功只按战果计算**（击落、旗舰伤害、炮台、战舰、拦截、胜利），不显示任何消费金额；送礼本身不加战功。
- 等级跟着抖音用户ID存档：等级越高，AI躲弹越灵活、战机血量越高；升级解锁涂装。
- 本周战功榜每周一清零。人少时自动补灰色「NPC」战机，NPC 不进榜单。
- 开局倒计时页面会一屏展示全部规则和礼物效果。

## 存档

存在这台电脑、这个浏览器的 localStorage 里。设置面板可以导出 / 导入（导入前自动备份）/ 清空（需两次确认）。不要清除这个网站的浏览数据；重要直播前后导出一次留底。

## 部署（Cloudflare Pages）

纯静态，不用构建：Pages 项目连接 `kaleomi/games`，**根目录填 `starship-barrage`**，构建命令留空，输出目录 `/`。

## 已知限制 / 下一步

- 抖音对「挂机直播」有规则，游戏可以不需要主播操作，但直播间最好仍有人出镜，上线前确认平台规则。
- 还没接抖音官方直播玩法接口，所以没有「小摇杆」王牌驾驶席；目前通过熙梦读取弹幕礼物。
